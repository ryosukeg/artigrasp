**Box：現在状態を使う行動補正・差分モデル・適応終了の統合検証報告**

対象：`box_dynamics_guidance` に保存された学習結果と、seed202のnormal／開閉角OOD比較。既存のJSON・実装・監査記録を照合して一つに整理した。今回の文書作成に伴う追加学習・物理シミュレーションは行っていない。

**1. 検証で確認できたこと**

差分モデルは、現在の蓋角度と基部位置を基準に「0.2秒後にどれだけ変わるか」を学習する。同じ検証遷移で、元の絶対状態モデルより角度RMSEが33.2%、位置成分RMSEが84.0%低下した。ただし、その改善は今回のOOD操作の成功率向上にはつながっていない。

以下はPPO単体／元モデル補正／差分モデル補正の順。各数値の分母は100試行である。元モデル補正と差分モデル補正はいずれも、固定したPPOに予測器で選んだ行動補正を加える方式を指す。

| 判定 | 条件 | PPO単体 | 元モデル補正 | 差分モデル補正 |
|---|---|---|---|---|
| 固定：開閉3秒の1時点成功 | normal | 9/100 | 11/100 | 9/100 |
| 固定：開閉3秒の1時点成功 | OOD | 19/100 | 19/100 | 15/100 |
| 適応：3条件を0.5秒維持 | normal | 9/100 | 10/100 | 9/100 |
| 適応：3条件を0.5秒維持 | OOD | 20/100 | 21/100 | 18/100 |

OODでは、固定時間の成功率は元モデル19%に対して差分モデル15%。適応終了の成功維持率は元モデル21%に対して差分モデル18%だった。適応終了の「終端1時点成功」では元モデルは22%になるが、これは0.5秒維持した21%とは別である。

時間制限で失敗していた一部の試行は、適応終了によって成功した。代表例OOD0037では差分モデルの角度誤差が0.500646 radから0.106596 radに下がった。一方、OODの平均角度誤差と平均位置誤差は、延長後に3方式とも増えた。少数例の救済と全体の誤差改善は別の結果である。

持上げを含む複合タスクの成功は、固定・適応の両評価、normal・OOD、全3方式で0/100。したがって、ここでの9〜22%を複合タスク全体の成功率と読んではいけない。すべて単一seed・既に観察した目標集合での探索的結果であり、一般的な優劣は確定していない。

**2. 「現在状態を補正する」の意味と、実際に変更した部分**

今回の実装には、混同しやすい三つの処理がある。

| 処理 | 実際の内容 | 今回の扱い |
|---|---|---|
| 現在状態に予測差分を足す | 未来の角度・位置 = 現在の実測値 + モデルが予測した変化量 | 差分モデルの予測を絶対状態へ戻す処理 |
| PPOの行動を補正する | 実行する右手首並進action = 毎stepのPPO出力 + 選択した補正z | 元モデル・差分モデルの両方で実施 |
| 開閉開始時の状態を正しく対応させる | 手のreset後のfinal_states[0]／final_obsを使う | 元・差分に共通するデータ整合性の処理 |

物理シミュレータ内の物体位置や角度を、予測値へ直接書き換える処理はない。観測ノイズを除く状態推定器を追加した実験でもない。毎回の実測状態から候補の未来を予測し、その結果に基づいて行動へ補正を加えている。

元モデルも現在状態を入力として受け取る。両モデルの違いは「現在状態を見るかどうか」ではなく、角度・位置の出力を絶対値として学習するか、現在値に足す変化量として学習するかである。

手のresetへの対応も差分モデル固有の改善ではない。step1260の既存保存配列`states[1260]`はreset前なので、予測・学習開始にはreset後の`final_states[0]`を使う。動画の該当フレームもこの状態に対応させている。今回の記録は、この対応を使った方式間比較であり、「誤ったreset前状態」と「修正後状態」を別群として比較した効果量はない。

**3. 実験全体の流れと共通条件**

```text
現在の左右観測・物体状態・元の目標
                 │
                 ├─ 固定PPO → 毎stepの左右action
                 │
                 └─ 7個の右手首補正候補z
                       ↓
                0.2秒後の物体状態を予測
                元モデル：絶対状態を直接出す
                差分モデル：角度・位置に現在値を加えて復元
                       ↓
                目標への角度・位置・姿勢誤差で採点
                       ↓
                最小costのzを選び20step保持
                       ↓
                PPOの右手首並進actionにzを加えて実行
                       ↓
                新しい実測状態を取得して再選択
```

PPO単体は常にz=0。予測器はPPOを置き換える制御方策ではなく、補正候補の比較に使う。

| 項目 | 条件 |
|---|---|
| 物体／方策 | boxのみ。公開PPOの重みを固定。最終開閉の右手もcooperative_right |
| 制御周期 | 0.01秒＝100 Hz |
| 補正対象 | 最終開閉の右手actionの並進3成分。前段、左手、右手回転・指は補正対象外 |
| 固定評価の時間 | 全1560step＝15.6秒。前段12.6秒＋最終開閉3秒 |
| 候補z | (0,0,0)、(±1,0,0)、(0,±1,0)、(0,0,±1)の7個 |
| 選択・保持 | 20step＝0.2秒ごと。固定評価では1試行15窓。保持中もPPOは毎step再計算 |
| 評価用参照 | 公式test split。seed202。normal100条件＋OOD100条件 |
| normal目標角 | 0.5〜0.6 rad（約28.6〜34.4度） |
| OOD目標角 | [0.2,0.4] ∪ [1.6,3.1] radと関節可動域の両端0.05 radを除く範囲との共通部分 |
| OODの内訳 | 区間長に比例して抽出。今回の小角14件、大角86件 |
| 実行形状 | 各条件100並列、物理24thread、PPO・予測器ともCUDA。方式間で試行順も統一 |

z=1はactionの単位であり、root座標で名目上1 mmの手首PD位置目標差に対応する。手が必ず1 mm動くという意味ではなく、毎stepの累積移動指令でもない。世界座標での差は、開閉開始時に定まるroot姿勢による回転を受ける。斜め方向やより強い補正への拡張は、この比較には含まれない。

採点は両モデル共通で、予測した未来状態を元の要求目標と比較する。

```text
cost(z) = (予測角度誤差 / 0.5 rad)^2
        + (予測基部位置距離 / 0.05 m)^2
        + (予測基部姿勢のSO(3)角距離 / 0.2 rad)^2
        + 0.01 × ||z||^2
```

姿勢の採点ではquaternionを正規化し、qと−qを同じ回転として扱う。角速度もモデルが予測するが、このcostには直接入らない。非有限値などの無効候補を除外し、全候補が無効ならz=0に戻す。設定は比較計画に固定されている。20step先の候補評価であり、複数窓の行動列を先読みして最適化する方式ではない。

根拠：[収集仕様](DATA_COLLECTION.md)、[特徴量](dataset.py)、[元モデルの補正選択](guidance.py)、[差分モデルの補正選択](guidance_delta.py)。

**4. 元モデルと差分モデルの詳しい違い**

**4.1 入力とネットワークは共通**

入力は窓開始時点の571成分。中間20フレームの動画や時系列を入力するモデルではない。

| 入力 | 次元 | 役割 |
|---|---|---|
| 右手のraw観測 | 276 | 手・物体・接触など、その時点でPPOが利用する観測 |
| 左手のraw観測 | 276 | 左手側の観測 |
| 現在の物体状態 | 8 | 基部位置XYZ＋quaternion wxyz＋蓋角度 |
| 元の要求目標 | 8 | 目標位置XYZ＋quaternion wxyz＋蓋角度 |
| 候補補正z | 3 | 一定に保持する右手首の並進action補正 |
| 合計 | 571 | 各候補で最後の3成分を入れ替えて予測 |

ネットワークは両方ともMLP `571 → 256 → 256 → 256 → 9`、隠れ層はReLU、学習パラメータ数は280,329。差分モデルは元モデルの重みに後付け補正を学習したものではなく、同じ規模のネットワークを新規初期化して学習した。

**4.2 9出力のうち4成分だけを差分化**

| 予測対象 | 次元 | 元モデルの教師 | 差分モデルの教師 | 差分モデルの絶対状態への復元 |
|---|---|---|---|---|
| 蓋角度θ | 1 | θ(t+20) | θ(t+20)−θ(t) | θ(t)＋予測Δθ |
| 蓋角速度ω | 1 | ω(t+20) | ω(t+20) | そのまま |
| 基部位置p | 3 | p(t+20) | p(t+20)−p(t) | p(t)＋予測Δp |
| 基部姿勢q | 4 | q(t+20) | q(t+20) | そのまま。採点時に正規化 |

θは回転関節の蓋角度、pは物体基部の位置、qはwxyzのquaternionである。姿勢の教師と目標は開始姿勢に対して符号を合わせるが、姿勢の差分回転を学習しているわけではない。

例えば現在角度が0.80 rad、0.2秒後の実測角度が0.83 radなら、元モデルの正解は0.83、差分モデルの正解は+0.03となる。差分モデルが+0.02と予測した場合、未来角度は0.80+0.02=0.82 radと復元する。これは説明用の数値である。

各窓で加える現在値は、その窓開始時の新しい実測値である。以前の予測に差分を足し続ける処理ではない。実装では角度は右raw観測index273、位置はglobal state index122:125を使い、学習側と対応を揃えている。

元モデルは「現在値を未来へ引き継ぐこと」もネットワーク内で表現する必要がある。差分モデルではその引継ぎを明示的な加算で表し、角度・位置の変化を学習対象にできる。短い時間であまり動かない対象では役立つと考えられるが、今回の実験だけで改善の機序を特定したわけではない。

**4.3 正規化と損失の比較条件**

入力の平均・標準偏差はtrainだけから求め、両モデルで完全一致。出力を割る標準偏差も、元の絶対値教師のtrain標準偏差を共通に使う。差分にした4成分の正規化中心だけを0に変更し、残り5成分の中心は元の平均を維持する。

したがって差分4成分について、次の等式が成り立つ。

```text
正規化した予測誤差
 = (予測Δ − (未来の実測値 − 現在の実測値)) / 元の標準偏差
 = ((現在の実測値 + 予測Δ) − 未来の実測値) / 元の標準偏差
```

学習lossは9成分の正規化二乗誤差の平均であり、絶対状態へ戻して比較しても同じ物理量の重みになる。「差分の標準偏差で割り直したためにlossの見かけが下がった」という比較ではない。

差分出力が0なら角度・位置は現在値維持になるが、ネットワークをゼロ重みで初期化してはいない。ネットワークの全出力が0でも、角速度・姿勢はtrain平均に復元されるため、それらまで現在値維持になるわけではない。姿勢の学習lossはquaternionの成分MSEであり、採点・タスク評価で使うSO(3)角距離と同じではない。

元モデル用と差分モデル用のcheckpoint型は別で、元モデル用selectorは差分checkpointの誤読込を拒否する。差分用selectorが現在値を加えてから、共通の採点関数へ渡す。

根拠：[差分教師の定義](delta_targets.py)、[元の学習器](train_model.py)、[差分学習器](train_delta.py)、[両モデルの比較検証](compare_delta.py)。

**6. モデル単体の予測精度と、その差分**

同一のval 2,985遷移に対して、0.2秒後の実測状態をどれだけ予測できたかを比較した。「状態維持」は現在の角度・角速度・位置・姿勢をそのまま未来予測とする基準である。PPO単体のタスク成功率とは別の基準で、実際の物理状態を静止させた実験ではない。

| 指標（小さいほど良い） | 状態維持 | 元モデル | 差分モデル | 差分−元 | 元比 | 状態維持比 |
|---|---|---|---|---|---|---|
| 蓋角度RMSE [rad] | 0.115336 | 0.140528 | 0.093844 | -0.046685 | -33.2% | -18.6% |
| 蓋角速度RMSE [rad/s] | 0.718340 | 0.695051 | 0.685823 | -0.009228 | -1.3% | -4.5% |
| 基部位置の成分RMSE [m] | 0.008517 | 0.103232 | 0.016503 | -0.086729 | -84.0% | +93.8% |
| quaternionの成分RMSE | 0.031970 | 0.136743 | 0.129292 | -0.007451 | -5.4% | +304.4% |
| 全9出力の正規化MSE | 0.107181 | 0.161677 | 0.130830 | -0.030847 | -19.1% | +22.1% |

差分化により角度・位置などの集約誤差は元モデルより改善した。状態維持に対しても角度は18.6%、角速度は4.5%改善した。一方、位置成分RMSEは状態維持の約1.94倍、quaternion成分RMSEは約4.04倍、全体MSEは22.1%大きい。全体MSEでは状態維持が最も小さい。

位置の値はXYZ成分をまとめたRMSEであり、位置ベクトル距離のRMSEではない。quaternionの値にもradの単位はない。また集約quaternion RMSEは改善したが、個々の出力すべてが改善したわけではなく、quaternion x成分は0.101056→0.107069と悪化している。

ここで使うvalはbest epochの選択にも用いた分割で、独立した最終testではない。予測対象も収集分布内の短時間応答であり、OOD目標での候補順位や閉ループの成功率を直接示さない。

**7. 実際の操作結果：固定3秒での3方式比較**

**7.1 指標と成功の定義**

| 指標 | 意味 | 成功閾値 |
|---|---|---|
| PE [m] | 最終物体基部位置と元の目標位置とのユークリッド距離 | <0.05 m（5 cm） |
| AAE [rad] | 最終蓋角度と元の目標角との絶対差 | <0.5 rad（約28.6度） |
| AE [rad] | 最終基部姿勢と目標姿勢とのSO(3)回転角距離 | <0.2 rad（約11.5度） |
| 最終3条件成功：paper_success | 上の3条件が終端1時点で同時成立 | 位置・蓋角度・姿勢すべて |
| 持上げ込み：ood_goal_success | 途中の持上げ達成＋最終3条件成功 | 今回の持上げ設定は高さ達成を要求 |
| strict_goal_success | 持上げ込み成功の角度閾値を<0.1 radにする | 基部位置・姿勢も要求 |
| 角度単独<0.1 rad | 蓋角度誤差だけが約5.7度未満 | 基部安定・持上げは要求しない |

閾値はすべて厳密な「未満」。本書は実物理終端のpaper系指標を使い、公式互換の`public_success`等とは区別する。今回の持上げは、指定の持上げ区間中に初期基部高さからの変化が要求0.15 mに対して誤差0.05 m未満になることを要求する。持上げ位置・姿勢も要求する別指標`lift_pose_success`は今回の複合成功条件には加えていない。

**8. 実際の操作結果：適応終了へ変更した場合と固定時間からの差**

**8.1 終了規則**

固定時間では全体15.6秒で打ち切った。適応評価では前段12.6秒を維持し、最終開閉は最低3秒・最大10秒、全体では通常15.6〜22.6秒となる。PPOと両予測モデルの重み、7候補、20step保持は共通で、終了規則を変更した。

| 優先順 | 終了理由 | 条件 |
|---|---|---|
| 1 | 無効 | 非有限状態・観測・actionやreset等。最低3秒を待たず失敗扱い |
| 2 | 成功維持 | PE<0.05 m、AAE<0.5 rad、AE<0.2 radが0.5秒連続で成立 |
| 3 | 観測上の停滞 | 直近2秒の蓋角度レンジ<0.02 rad、窓開始からの基部位置最大変位<0.002 m、姿勢最大変位<0.02 radをすべて満たす |
| 4 | 時間上限 | 開閉10秒に到達 |

成功維持と停滞による終了は開閉3秒以降に判定する。0.5秒維持は両端を含む51状態、停滞2秒は201状態で確認する。3秒時点でも、それ以前の直近0.5秒を使って維持判定できる。現在の1時点成功が成立している間は停滞判定を抑制し、成功維持の確認を待つが、10秒の上限は適用する。

停滞は物体の観測変化に基づく規則であり、到達不能の証明ではない。手が接触を探している場合や非常に遅い進行を止める可能性がある。また、成功維持の終了判定は途中の持上げを条件に含まない。

各試行の最初の終了時刻を固定して保存・評価する。100並列の形状を保つため、終了済み環境も内部では計算に残るが、その終了後の状態を評価へ加えない。最後の20step窓だけは途中で終了し得る。

規則の事前診断には既存valを使い、test成功率による閾値調整はしていない。ただし同じseed202の結果を観察した後の探索的追試であり、新規の未観察目標集合による最終検証ではない。

**10. 予測精度が改善しても成功率が改善しなかった理由をどう考えるか**

以下では、今回の記録で確認できた事実と、追加検証が必要な説明を区別する。

1. **全体の予測RMSEと候補の順位精度は異なる。** 制御で必要なのは、同じ状態で7候補のどれが良いかを見分けること。平均予測誤差が小さくても、候補間の小さな差を誤れば良い補正を選べない。差分モデルについて、広い状態集合で全候補を実測した順位精度はまだ確認していない。
2. **位置・姿勢の予測は状態維持より悪い。** 差分モデルでも位置成分RMSEは状態維持の約1.94倍、姿勢成分RMSEは約4.04倍。採点には角度以外の誤差も入るため、角度予測だけの改善で候補選択全体の改善は保証されない。どの誤差が今回の失敗を引き起こしたかは未特定である。
3. **学習分布と評価分布が異なる。** 学習目標は0.5〜1.5 rad、OODはその外側を含む。閉ループで自ら選んだ補正が作る状態も、ランダム補正による収集状態とは異なり得る。さらに学習データの開閉は3秒までで、適応評価の3〜10秒は学習時より長い経過時間を含む。
4. **短期costと最終成功条件は同一ではない。** 0.2秒後の二乗誤差を小さくする選択が、数秒後の成功維持や持上げ込み成功を最大にする保証はない。基部の位置・姿勢と蓋角度の間で結果が分かれることもある。
5. **補正できる動作の範囲が限られる。** 最終開閉の右手首並進だけを、ゼロまたは軸方向±1で補正する。前段の持上げ失敗や、指・回転・左手側に由来する問題を直接修正する構成ではない。ただし、この制約が今回の不改善の主因だと確定したわけではない。

補助診断として、元モデルの既存較正4条件・非ゼロ24候補では、0.2秒後の角度に対する実測補正効果の絶対値中央値は約0.000229 rad、予測効果は約0.005942 radだった。補正効果のRMSEは元モデル0.018821 rad、効果ゼロを予測する基準0.016908 radで、元モデルが候補効果を十分に識別できていない可能性を示す。ただし少量の探索的診断で、差分モデルやOOD全体にそのまま当てはめられない。[診断JSON](diagnostics/prediction_error_seed301.json)

同じ診断では、元モデルの検証lossの約57.3%が角速度成分に由来し、学習データには目標から基部が1 m以上離れた92窓があった。正規化や学習重点を検討する材料にはなるが、それらを除けば良くなると実証した結果ではない。今回の差分学習では、そのような失敗窓を追加除外していない。

この検証から確定できるのは、「同条件の遷移予測誤差は改善した」「この候補・採点・seedではOOD成功率改善を確認できなかった」「時間制限が成否に影響した例はあった」という範囲である。

**11.3 結論の適用範囲**

- 対象はboxのみ、単一seed202、normal100・OOD100条件。小角OODは14件しかなく、同じ参照の再利用もある。
- 2方式・3方式・適応版は同じ200目標に基づくため、400＋600＋600を独立な1,600条件の証拠として足し合わせない。

- 方式間でモデル規模・入力・収集データ・損失尺度を揃えたが、早期停止までの更新回数は異なる。PPO単体に対して追加学習・推論コストを揃えた比較でもない。
- 停滞判定は到達不能判定ではなく、終端成功と0.5秒維持も同じ指標ではない。適応終端の誤差は観測時間の差を含む。
